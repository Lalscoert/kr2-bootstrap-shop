# Bootstrap Shop

Учебный многостраничный интернет-магазин, разработанный в рамках контрольной работы №2 по дисциплине «Фронтенд и бэкенд разработка».

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

Проект представляет собой учебный интернет-магазин, интерфейс которого разработан с использованием CSS-фреймворка Bootstrap.

В проекте реализованы:

- главная страница;
- каталог товаров;
- страница товара;
- форма заявки;
- единая навигация;
- карточки товаров;
- модальное окно;
- адаптивная Bootstrap-сетка;
- дополнительный компонент Accordion.

## Используемый фреймворк

Bootstrap 5.3.8.

## Способ подключения Bootstrap

Bootstrap подключён через CDN.

CSS Bootstrap подключается перед собственным файлом `css/custom.css`.

JavaScript-компоненты Bootstrap работают через `bootstrap.bundle.min.js`.

## Страницы проекта

- `index.html` — главная страница магазина;
- `catalog.html` — каталог товаров;
- `product.html` — страница с информацией о товаре;
- `order.html` — форма оформления заявки.

## Реализованные Bootstrap-компоненты

В проекте используются:

- `navbar`;
- `card`;
- `btn`;
- `badge`;
- `alert`;
- `modal`;
- `form-control`;
- `form-select`;
- `input-group`;
- `form-check`;
- `accordion`.

Также используется Bootstrap-сетка:

- `container`;
- `row`;
- `col-*`;
- `col-12`;
- `col-md-*`;
- `col-lg-*`;
- `g-*`.

## Самостоятельные доработки

Помимо базовых требований методических указаний были выполнены дополнительные доработки:

- добавлен единый подвал сайта на основные страницы;
- подвал прижат к нижней части окна браузера с помощью Flexbox;
- доработан файл `custom.css`;
- улучшена визуальная целостность страниц;
- унифицировано расположение навигации и подвала;
- улучшено расположение элементов каталога;
- добавлены дополнительные настройки отображения карточек и блоков страницы.

## Проверка проекта

Для проверки проекта необходимо:

1. Открыть `index.html`.
2. Проверить работу навигации.
3. Перейти на `catalog.html`.
4. Проверить отображение карточек товаров.
5. Проверить открытие и закрытие модального окна.
6. Перейти на `product.html`.
7. Проверить информацию о товаре и Accordion.
8. Перейти на `order.html`.
9. Проверить отображение формы заявки.
10. Проверить страницы на разных размерах экрана через DevTools.

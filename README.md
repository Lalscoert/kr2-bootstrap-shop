# Bootstrap Shop

Учебный многостраничный интернет-магазин, разработанный в рамках контрольной работы №2 по дисциплине «Фронтенд и бэкенд разработка».

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

Проект представляет собой учебный интернет-магазин, интерфейс которого разработан с использованием CSS-фреймворка Bootstrap.

В проекте реализованы:

- главная страница;
- каталог товаров;
- страница товара;
- форма заявки;
- единая навигация;
- карточки товаров;
- модальное окно;
- адаптивная Bootstrap-сетка;
- дополнительный компонент Accordion.

## Используемый фреймворк

Bootstrap 5.3.8.

## Способ подключения Bootstrap

Bootstrap подключён через CDN.

CSS Bootstrap подключается перед собственным файлом `css/custom.css`.

JavaScript-компоненты Bootstrap работают через `bootstrap.bundle.min.js`.

### Назначение основных файлов

- `index.html` — главная страница магазина GGWP.
- `catalog.html` — каталог игровых устройств.
- `product.html` — страница Logitech G Pro X Superlight.
- `product-varmilo.html` — страница Varmilo Minilo 75%.
- `product-headset.html` — страница Logitech G Pro X Wireless.
- `order.html` — оформление заказа.
- `support.html` — страница поддержки и контактной информации.
- `css/custom.css` — пользовательские стили проекта.
- `images/` — изображения товаров, логотип и фоновые изображения.

### Дополнительные страницы и функциональность

В ходе доработки проекта были добавлены дополнительные страницы и расширена логика взаимодействия между ними.

Добавлены:

- отдельная страница товара `product-varmilo.html` для клавиатуры Varmilo Minilo 75%;
- отдельная страница товара `product-headset.html` для гарнитуры Logitech G Pro X Wireless;
- страница поддержки `support.html`;
- расширенная страница оформления заказа `order.html`.

Каждая страница товара содержит изображение, описание, цену, таблицу характеристик, Accordion с дополнительной информацией и кнопку перехода к оформлению заказа.

### Каталог товаров

Каталог был переработан и теперь содержит три отдельных товара:

- Logitech G Pro X Superlight;
- Varmilo Minilo 75%;
- Logitech G Pro X Wireless.

Карточки товаров содержат изображение, категорию, название, цену и ссылку на отдельную страницу устройства.

Также в каталоге добавлено модальное окно «Помочь с выбором», из которого пользователь может перейти на страницу поддержки.

### Страница поддержки

На странице `support.html` размещена контактная информация магазина:

- e-mail;
- телефон;
- Telegram;
- график работы поддержки.

Страница предназначена для помощи пользователю при выборе игрового устройства и получения консультации.

### Оформление заказа

Страница `order.html` была переработана в полноценную страницу оформления заказа.

Реализованы:

- ввод контактных данных;
- выбор товара;
- комментарий к заказу;
- согласие на обработку персональных данных;
- отображение выбранного устройства;
- динамическое изменение названия, изображения и цены товара;
- автоматическая передача выбранного товара со страницы устройства через параметры URL;
- модальное окно успешного оформления заказа.

### Дополнительная адаптация интерфейса

Для новых элементов интерфейса были добавлены собственные стили и media queries.

Дополнительно адаптированы:

- страницы товаров;
- каталог;
- форма оформления заказа;
- блок итоговой стоимости;
- страница поддержки;
- карточки устройств;
- навигация на мобильных устройствах.

Все страницы проекта выполнены в единой визуальной стилистике GGWP.

## Проверка проекта

Для проверки проекта необходимо:

1. Открыть `index.html`.
2. Проверить работу навигации.
3. Перейти на `catalog.html`.
4. Проверить отображение карточек товаров.
5. Проверить открытие и закрытие модального окна.
6. Перейти на `product.html`.
7. Проверить информацию о товаре и Accordion.
8. Перейти на `order.html`.
9. Проверить отображение формы заявки.
10. Проверить страницы на разных размерах экрана через DevTools.
